## 4. 红线（不许做什么）

- **串口互斥**：`vohive` 与 `freepbx` 不能同时跑（都独占 `/dev/ttyUSB2`）。
- **不许源码遮蔽**：容器不许挂 `projects/openvohive`；不许 `docker cp` 热改容器。
- **模块不开数据**：`network_enabled=false`，防抢默认路由。
- **凭据**：Bark `device_key` / Web 密码只落 `.env` 与 `data/config.yaml`，不入库、不进对话。
- **Bark 的 `device_key` 环境变量无效**（viper 对未注册默认值的键不读 env）：只能写 `config.yaml` 或 `PUT /api/settings/notifications`。

## 5. 已知坑（踩过的）

- 只挂 `/dev` 不挂 `/sys` → 加设备报 `未找到匹配 IMEI 的设备: <IMEI>`。
- 上游 `.gitignore` 含 `docs/*`：项目文档靠 `.gitignore` 末尾的 `!docs/`、`!docs/*` 解禁（别删这两行）。
- `web/package.json` **没有 test 脚本**（上游遗留 `web/tests/*.test.ts` 跑不了）→ 已登记在 `scripts/ci-test-map.txt` 的 `SKIPPED:` 行，属显式跳过而非静默。
- 官方 `docker-entrypoint.sh` 把配置持久化到 `/app/data/config.yaml`（viper `AutomaticEnv` 读 `PROXY_*`）；我们的 `deploy/docker-entrypoint.sh` 与之对齐。
- **配置优先级是「环境变量 > config.yaml」**（实测）：容器里设了 `PROXY_WEB_PASSWORD` 时，config.yaml 里的 `web.password` 会被忽略（生产上 config.yaml 写 admin、实际登录用的是 env 的 `vohive2026`）。冒烟/部署必须用 env 传凭据，别指望挂文件。
- **登录有限流**：10 次 / 2 分钟 / IP（`internal/api/server.go` 的 `allowLoginAttempt`）。写轮询脚本别每 2 秒敲一次登录 —— 首次 CI 就是这么拿到连串 429 的；统一走 `scripts/wait-ready.sh`（就绪判定用免鉴权的 `GET /`，登录最多 3 次间隔 20s）。
- 容器未给 `PROXY_WEB_PASSWORD` 时，入口脚本会随机生成密码并打印在 `docker logs` 里（每次重启都换）。
